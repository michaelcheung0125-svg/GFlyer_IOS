## Rust crates linked by idevice

`libidevice_ffi.a` also statically links the Rust crates that idevice depends on
and the Rust standard library. Their licenses and full license texts are listed
in the app's settings (裝置設定) under 關於 › 開放原始碼授權, from
`GFlyerIOS/Resources/OpenSourceLicenses.json`. That file is generated by
`scripts/open_source_licenses.py` from idevice's `Cargo.lock` with the same
package, target and features as `scripts/build_idevice.sh`, and CI checks that
it matches. Two crates (`plist-macro` and `plist_ffi`) declare the MIT license in
`Cargo.toml` but ship no license file, and their repositories have none either;
the list shows the standard MIT text with the author named in `Cargo.toml`.

## Personalized Developer Disk Image source

The app can download Personalized DDI files from the public
`doronz88/DeveloperDiskImage` repository at revision
`5423e4e955fbb3a9eef3e1212acfbfc6e7a26236`. The binary files are not included
in this repository. Each downloaded file is checked against a pinned SHA-256
digest before use.

## App artwork

The flying pig artwork in `GFlyerIOS/Resources/Assets.xcassets` (the app icon,
`GFlyerIcon` and `GFlyerMarker`) is JetPiggy's own brand artwork, not
third-party material. It is generated from the JetPiggy brand masters by
`scripts/make_brand_art.py`, and it is not covered by any open source license.
